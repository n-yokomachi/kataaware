# 場面 4（潜る） 設計

- 作成日: 2026-09-21
- 対象: 場面 4。端末から他人の記憶へ潜り、人から人へ渡り歩く。旧 4（記憶 1）と旧 5（記憶 2）はこの場面の中に取り込む。自室へ戻る小休止を場面 5 とし、庭の記憶（場面 6）以降の番号は変えない
- 前提: `2026-09-15-game-design.md` 2・4・8 節、`2026-09-16-scenario-design.md` 1・3 節、`2026-09-16-unity-port-design.md` のスクリプト構成はそのまま有効。本文の元は `docs/reference/kataaware-original.md`
- 位置づけ: 実装前の意思決定記録。中身の並び（6 節）は叩き台で、オーナーが直す

## 1. 決定事項

- 記憶の中では体は主が動かし、プレイヤーは見回すことだけができる。これまでの方針どおり
- どの記憶も「名前を呼ばれた瞬間」から始まり、声は必ず画面の外から来る
- 一つの記憶は長さが決まっていて、尽きれば勝手に次へ切り替わる。切り替えは暗転を挟まず、前の絵から次の絵へ直に切り替える。長さは、呼ばれる前に数秒その体でいて、呼ばれ、振り向き、相手を見つけて板が出るまでの間が取れるだけ置く。子どもと老人は 45 秒、他は 15〜20 秒
- 記憶の中で人に目を留めると、その脇にホログラムの板が浮く。板の `潜る` を押すと、その人の記憶へ飛ぶ。渡り歩く道筋はプレイヤーが決める
- 同じ板に `切断` がある。初めは小さく灰色で押せない。人を渡るたびに大きくなり、`潜る` と同じ大きさになったところで押せるようになる。どちらを押すかはプレイヤーに任せる
- 眩暈は人を渡るたびに一段濃くなる。上限も回復もない。管理はさせない
- 最初の一人は端末が決める（列の一番上、母に呼ばれる子ども）。プレイヤーが誰も選ばずに記憶が尽きたときは、端末が次を選ぶ。選ぶ順は場面 3 の列の並び、列が尽きたら一覧から無作為
- `切断` を押すと画面が裂けて自室へ戻る。座ったまま、眩暈、煙草、「次の記憶で今日は最後にしよう」。ここが場面 5
- 場面 5 でモニターを調べると最後の一人へ潜る。これは端末が無作為に選んだことにし、行き先は庭（場面 6）
- 庭の記憶が途中で終わるのは、主の端末が網から離れて流れが止まるから。**主の側から意図して切ることはできない。** 庭の終わり方は他の記憶が尽きるときと同じ直の切れ方で、プレイヤーの操作とは結び付かない
- 点数・値踏み・操作の難しさは入れない。この場面で伝えることは、数十人の頭を覗いて回る毎日の手つきであって、上手さではない

## 2. 取り下げたこと

相談で出して却下されたもの。同じ案を出し直さないために残す。

- 顔に照準のような括弧を掛けて「自分を探す」操作。プレイヤーは主人公が自分を探しているとは意識していないので、動機が繋がらない
- 眩暈をゲージにして耐えるか切るかを管理させること
- `E 次へ` で次の記憶へ送る操作。それだけなら自動でよい
- 記憶をチップに記録して持ち帰り、売り物として値踏みさせること
- 板が出るまでの時間や主の体の癖を、掴まえる難しさにすること
- 庭の女性に「防壁あり」の板を出すこと。潜っている時点で防壁の内側にいるので成り立たない
- 記憶の中で時間を巻き戻す操作。意図が伝わらない
- 自室に戻ったとき、モニターの列を渡ってきた順に並び替えて見せること

## 3. 見え方

### 右上の行

記憶を流しているあいだ、画面の右上に端末と同じ緑の小さな字で、いま潜っている人の行を出しておく。場面 3 のモニターの列と同じ書式で、番号は付けない（列に番号が無いので）。

```
女　6　『メイ』　2156/03/02 07:14
```

人を渡ると行が変わる。字幕帯はこの場面では出さない。呼ばれた言葉はこの行が持っている。

### 板

人が視界の中央寄りに入って半秒すると、その人の肩の脇に掌ほどの四角い板が浮く。端末と同じ緑、半透明、縁だけ線。人が動けば板も一緒に動く。目を外して半秒で消える。

```
女　34　『ママ』　2156/03/02 09:02
E 潜る　　　切断
```

一行目はその人の行。二行目が操作。`切断` は初め二行目の右に、`潜る` の四割ほどの大きさで灰色に置く。人を渡るたびに一段大きくなり、決めた人数（仮に 8 人）で `潜る` と同じ大きさになって緑に変わる。以後は上下（マウスの車輪、または矢印）で `潜る` と `切断` を選び、E で決める。同じ大きさになるまでは E は常に `潜る`。

一つの記憶に人が何人いても、板が出るのは目を留めている一人だけ。

### 眩暈

既にある眩暈（ぼやけと二重像、視点の漂い）をそのまま使う。潜った直後は薄く、人を渡るたびに一段濃くする。`切断` が同じ大きさになる人数で最大に達し、以後は最大のまま。板の字が二重に見えて読みにくくなるのは、この結果であって狙いではない。

### 切り替え

- 潜る・渡る: 直に切り替える。黒も白も挟まない。音は場面 3 のジャックの音から作る（後で決める）
- 記憶が尽きる: 同じく直に次へ。終わりの合図は入れない
- 切断: 画面が裂けて（縦の筋が入って左右へ割れる、0.4 秒）、自室
- 庭の終わり: 記憶が尽きるときと同じ。直に切れる

## 4. 進行

```
場面 3「潜る」→ 記憶 A（端末が決めた最初の一人）
  ├ 板の「潜る」→ その人の記憶へ（プレイヤーの選択）
  ├ 尽きた → 端末が次を選ぶ（列の順、次に無作為）
  └ 板の「切断」（同じ大きさになった後だけ）→ 場面 5
場面 5 自室。座ったまま。眩暈。煙草。「次の記憶で今日は最後にしよう」
  └ モニターを調べる → 庭（場面 6）
```

- 一度潜った人の記憶へも戻れる。同じ絵が流れる
- 端末が次を選ぶとき、既に潜った人は飛ばす。列も一覧も尽きたら、潜った人を含めて無作為
- 人数の上限は置かない。`切断` を押すまで続く

## 5. 体の差

`2026-09-15-game-design.md` 4 節の三つの値を記憶ごとに持つ。加えて色味と、音の聞こえ方を持つ。

| 値 | 内容 | 幅 |
|---|---|---|
| 目線の高さ | 主の目の高さ。m | 0.9〜1.9 |
| ぼやけ | 近くがぼやける（老眼）か、遠くがぼやける（近視）か、鮮明か | 三択と強さ |
| 速さ | 主の体の動きの速さ。基準を 1 とした倍率 | 0.6〜1.6 |
| 色味 | 記憶ごとの Volume（Color Adjustments）。白飛び、褪色、橙、青 | 記憶ごと |
| 聞こえ方 | 耳の詰まり（低域通過）と心音の有無 | 記憶ごと |

視野角は動かさない（酔い対策）。歩行中の頭の揺れも入れない。主の体の動きは、記憶ごとに固定のアニメーションで持ち、プレイヤーの入力では動かない。

## 7. 場面 5（自室・小休止）

場面 3 の部屋にそのまま戻る。座ったまま、ジャックは挿さったまま、モニターは灯ったまま。

- 戻った瞬間は眩暈が最大。数秒かけて薄れる（既にある Daze の減衰）
- 煙草は場面 1 の煙草の演出を使う。吸い終わりまで操作は止める
- 独白は一行だけ。「次の記憶で今日は最後にしよう」
- 調べられるのはモニターだけ。印は「潜る」。調べると二択なしで庭へ
- 部屋を歩かせない

## 8. 舞台と音

### 舞台

一つのシーン（Dive）に全部の場所を無効のまま置き、潜るときに一つだけ有効にする。読み込みを挟むと直に切り替えられない。

| 場所 | 出どころ |
|---|---|
| 団地の外階段・踊り場 | 新規。階段一本と踊り場、ドア二つ、手すり |
| 公園のベンチ | 新規。ベンチ、地面、鳩、遠くの木 |
| 電車 | 新規。座席二列と吊り革、窓の外は流れる灯り |
| 台所・戸口・階段 | 場面 3 の部屋の台所と玄関を使い回し、色味を変える |
| 教室 | 新規。机の列、黒板、窓 |
| 団地の部屋の中 | 場面 3 の部屋を使い回し、目線と色味を変える |

新規の場所は、暗がりと色味で誤魔化せる最小の箱にする。人は場面 2 の買い手と同じ模型で、顔は背中・逆光・にじみで見せない。

### 音

- 呼ぶ声: 英語の合成音声をぼかしたもの（シナリオ設計 1 節の方針）。記憶ごとに一つ
- 環境音: 場所ごとに一つのループ
- 潜る・渡る: 一つの短い音。場面 3 のジャックの音から作る
- 眩暈: 段が上がるごとに耳の詰まりが強くなる（低域通過の閾値を下げる）
- 心音: 体の差の一つとして、記憶によっては入れる

## 10. テスト

- `DiveChain`: 最初の一人が列の一番上であること。板で選べばそこへ飛ぶこと。選ばずに尽きれば列の順、列が尽きれば無作為であること。`切断` が決めた人数まで押せず、それ以降は押せること。潜った人を端末が飛ばすこと
- `DiveRoster`: 一覧の飛び先がすべて一覧の中にあること。列の 6 人が一覧にあること。同じ場所の対が同じ場所を指していること
- `HoloPanel` の二行目の大きさ: 0 人で四割、決めた人数で十割、途中は単調

## 11. 決めていないこと

- `切断` が同じ大きさになる人数（仮に 8）
- 板が出るまでと消えるまでの秒数（仮に 0.5）
- 一覧の人数と名前。6 節は 16 人の叩き台
- 板を人の体のどこに出すか。肩の脇を仮とする
- 場面 5 を `Connect.unity` の戻りにするか別シーンにするか
- 潜る・渡る音の作り方
- 庭の女性に板を出すか。あの人が誰かという仕掛けに触れるので、場面 6 の本文と一緒に決める
