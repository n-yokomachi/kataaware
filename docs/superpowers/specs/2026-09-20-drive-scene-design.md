# 場面 8（車内） 設計

- 作成日: 2026-09-20
- 対象: 場面 8。暗転明けにアパートメントの共用ガレージでオフロード車に乗り込み、以降は運転席の一人称のまま、景色の帯が移り変わる
- 前提: `2026-09-15-game-design.md` 3 節の場面構成、`2026-09-16-scenario-design.md` の文体、`2026-09-16-unity-port-design.md` のスクリプト構成はそのまま有効。本文の元は `docs/reference/kataaware-original.md`
- 位置づけ: 実装前の意思決定記録

## 1. 決定事項

- ガレージは歩かせる。暗転明けにガレージの隅に立ち、車まで歩いて運転席のドアを調べると乗り込む。場面 1・2 と同じ操作感を保ち、車の外観を一度見せる
- 車は原点に固定し、世界のほうを流す。道と沿道を帯（タイル）にして手前へ送り、後ろへ抜けた帯を前へ回して並べ直す
- 景色の帯は 5 つ。帯と帯の切れ目は暗転で、そこに原作の車中の独白を流す
- **独白は自動では始まらない。** 帯ごとに決めた対象を調べたときだけ始まる。調べるまでは黙って走り続ける
- **時間や走行距離で暗転しない。** 独白を送り切ったあと、しばらく黙って走る間を置いてから暗転する。この間だけは秒数で持つ（仮に 5 秒）
- **暗転に入るのは切り替え、明けるのはフェードイン。** 黒へはフェードアウトせず一瞬で落とす。場面 1 のドアを閉める暗転と同じ扱い
- 運転操作はさせない。帯 5 は原作どおり手動運転だが、ハンドルを握る姿だけで、入力は受け付けない
- 調べる対象は二種類。帯ごとに一つの「きっかけの対象」が独白を始め、それとは別に、読んでも帯が進まない任意の対象を置く。帯 5 のきっかけである「窓を開ける」が場面 9 への切れ目になる

## 2. 景色の帯

| # | 景色 | 空と灯り | 路面 | 走り |
|---|---|---|---|---|
| 1 | 倫敦の外れ。ネオンの名残、高架の下 | 夜。ナノマシンの黒雲。ネオンの照り返し | 濡れた舗装。まだ雨 | 自動 |
| 2 | 夜の高速。街灯の列、対向車 | 夜。街灯の橙が一定の間隔で流れる | 舗装。乾いていく | 自動 |
| 3 | 深夜の幹線。両脇は木立 | 深夜。街灯が絶え、ヘッドライトだけ | 舗装 | 自動。末尾で仮眠 |
| 4 | 明け方の丘陵。石垣と牧草地 | 薄明と霧。低い位置からの光 | 舗装。所々荒れる | 自動 |
| 5 | 朝靄の未舗装路。黄金色の小麦畑 | 朝。薄青い高い空、千切れ雲 | 未舗装。土と轍 | 手動（姿だけ） |

帯 3 の末尾の暗転が仮眠にあたる。ここだけ黒のまま置く時間を長く取れるよう、暗転にかかる値は帯ごとに持つ。

帯 1 から帯 5 へ向かって、倫敦の黒雲から抜けて空が開いていく。色味は場面ごとの Volume（Color Adjustments）で寄せる。

## 3. 世界の流し方

`DriveWorld` が受け持つ。

- 道は一定長のタイルを N 枚の環にして、毎フレーム手前（-z）へ送る。1 枚が車の後ろの閾値を越えたら、環の一番先へ N 枚分まとめて動かし、今の帯の表で沿道を並べ直す
- 沿道の物は帯ごとの表で持つ。表は「何を・どれだけの間隔で・道からどれだけ離して・どれだけばらけさせて」を並べたもの。街灯・木立・石垣・電柱・麦・標識・対向車
- 対向車だけは別の環に乗せ、道より速く流す。沿道と同じ環に乗せると並んで走っているように見え、向かってくる感じが出ない。ヘッドライトの点だけで、車体は作らない
- 速度は帯の値。タイルの送り、沿道の送り、車体の揺れ、走行音の高さがこの一つの値から出る
- 座標は原点付近に留まるので、遠くへ行っても揺れや影が粗くならない

ガレージは原点の周りに建てる。乗り込んだ時点で伏せ、タイルの環を回し始める。

## 4. 車と視点

- 運転席に固定。ハンドル・ダッシュボード・メーター・助手席・ドアの内張り・フロントガラス・ルームミラーを作る
- 視線移動は既存の `HeadTurn` と `EyeSway` を流用する。移動はしない
- 運転席に主人公の体を座らせる（頭は一人称のカメラに映さない）。帯 1〜4 は腕組み（原作「自動運転に任せて私は腕組みをしながら考える」）、帯 5 はハンドルに手を乗せる。どちらも姿だけで、操作には繋がらない。腕組みの腕は体の真下にあり、下を向ける角度（40° まで）では画面に映らない。それでよい（腕組みは独白で伝わる）
- 車体の揺れは速度と路面から出す。舗装はごく小さく、未舗装は粗く。既存の `Sway` と同じ考え方で、カメラそのものを動かす

## 5. 調べる対象

対象は二種類ある。**きっかけの対象**は帯ごとに一つで、調べるとその帯の独白が始まり、送り切ると帯が終わる。**任意の対象**は読んでも帯は進まない。

| 帯 | きっかけの対象 | id |
|---|---|---|
| 1 | 助手席のメモリーチップの束 | `drive.chips` |
| 2 | アクセスログの写し。エディンバラ近郊の町の名 | `drive.log` |
| 3 | ルームミラー。自分の顔は映らない角度 | `drive.mirror` |
| 4 | メーターの脇の古い写真立て | `drive.photo` |
| 5 | 窓を開ける | `drive.window` |

どの帯にどれを割り当てるかは文面と合わせてオーナーが決める。上は仮の割り当てで、`DriveScript` の値として差し替えられる。

任意の対象（ラジオ、上着のポケット、給油計など）は帯を問わず置く。どちらの種類も一度調べたら終わり（場面 2 の通りの板と同じ扱い）。

きっかけの対象は、その帯に入るまで出さない。`drive.window` は帯 5 に入って初めて現れる。

## 6. 進行

`DriveDirector` が受け持つ。場面 2 の `AlleyDirector` と同じ役どころ。

1. 乗り込む → ガレージを伏せ、帯 1 を並べて流し始める
2. 黙って走る。プレイヤーは景色を眺め、任意の対象を調べられる。ここに終わりは無い
3. その帯の**きっかけの対象**を調べると、独白が字幕で出る。送り方は場面 1・2 と同じで、プレイヤーが自分の速さで送る
4. 最後の行を送っても、すぐには暗転しない。**余韻の間**だけまた黙って走る
5. 余韻が明けたら一瞬で黒へ切り替える。黒のまま次の帯を並べ、フェードインで明ける
6. 帯 5 だけ独白の先が無い。代わりに `drive.window` を調べて送り切ると、黒のまま車を止めて場面 9 へ（下の「場面 9 へのつなぎ」）

**帯が終わる条件は、きっかけの対象を調べて独白を送り切ったことだけ。** 経過時間でも走行距離でも進まない。調べなければいつまでも走っていられる。

黒へ落とすのは切り替えなので、そこに値は要らない。秒数で持つ値は三つで、どれも帯ごとに持つ。

| 値 | 仮置き | 意味 |
|---|---|---|
| 余韻の間 | 5 秒 | 独白を送り切ってから黒へ切り替わるまで。黙って走る |
| 黒のまま置く時間 | 実装時に仮値 | 切り替わってから明け始めるまで。仮眠（帯 3 の末尾）だけ長く取る |
| 明けるフェード | 実装時に仮値 | 黒から次の帯へ浮かび上がる長さ |

どれも仮置きで、実画面を見てからオーナーが決める。独白の本文と行数も同じ。

**場面 9（村）へのつなぎ。** 帯 5 だけは黒から明けない。`drive.window` を調べると窓が下り、麦の風が入ってくる。
独白を送り切ったら次の順に進む。段取りは `ArrivalClock`（純粋な C#）が持ち、`DriveDirector` が音と画面に繋ぐ。

1. 帯の余韻の間だけ走る。値はほかの帯と同じく `DriveBand.afterglow` で、帯 5 の分を持つ。
   いまは 30 秒（家々が通り過ぎるところを映すため。シナリオ設計 7.2。10 秒では家が目の前まで来なかった）
2. 一瞬で黒へ切り替える。ほかの帯の切り替えと同じ
3. 黒のまま `CarStopHandbrake.wav`（止まる・ハンドブレーキ・エンジンが続く。11.4 秒）を鳴らす。
   走行音と麦の風は、黒へ入ったところから止まる音に合わせて、両端を緩めて 0 まで下げる
4. 止まる音が鳴り終わったら、間を置いて `CarDoorShut.wav` を鳴らす
5. ドアを閉める音から 2 秒後に、村（`Village.unity`）へ切り替える。暗転を挟まず、村は明けた状態で映る

| 値 | 仮置き | 意味 |
|---|---|---|
| 走行音と麦の風を下げきるまで | 5.7 秒 | 黒へ入ってから。止まる音の中で車が止まりきるのが 5.7 秒あたり |
| 止まる音からドアまでの間 | 0.6 秒 | 止まる音が鳴り終わってから、ドアを閉める音を鳴らすまで |
| ドアから村まで | 2 秒 | ドアを閉める音を鳴らしてから、村へ切り替えるまで |

値は `DriveDirector` の「村へ」にあり、Inspector で変えられる。止まる音の長さは素材の長さをそのまま使う。
黒のあいだは操作を止める。村への切り替えは場面 8 の `SceneFlow.nextScene`（`Village`）が受け持ち、
次の場面へ進むときは暗転を足さない決まり（`SceneExit.FadesOut`）に従う。村には `SceneFlow` が無いので、
黒から明けるフェードも掛からない。

## 7. ファイル構成

既存の路地裏と同じ並びに揃える。

| 役目 | ファイル |
|---|---|
| シーン | `Assets/Scenes/Drive.unity` |
| 組み立て | `Assets/Editor/BuildDrive.cs` |
| 見直し | `Assets/Editor/CheckDrive.cs` |
| 文面の書き出し | `Assets/Editor/WriteDriveScript.cs` |
| 帯の進行と暗転 | `Assets/Scripts/Flow/DriveDirector.cs` |
| 対象の id | `Assets/Scripts/Flow/DriveIds.cs` |
| タイルの環と沿道 | `Assets/Scripts/Fx/DriveWorld.cs` |
| 帯の定義（純粋な C#） | `Assets/Scripts/Data/DriveBand.cs` |
| 文面 | `Assets/Data/DriveScript.asset` |

`CheckDrive` は `BuildDrive` の最後に必ず走らせる。見るのは次のとおり。

- タイルの環に隙間や重なりが無いか（送る幅と 1 枚の長さが合っているか）
- 沿道の物が道の上に出ていないか
- 調べる対象のピンが物に埋まっていないか
- 文面の id とシーンに立てた対象の id が食い違っていないか
- 帯の表に、そこで使えない物が混ざっていないか
- どの帯にもきっかけの対象がちょうど一つ割り当たっているか

## 8. テスト

絵に依らない判定を EditMode テストで確かめる。

- `DriveBand`: 帯の順送り。きっかけの対象を調べるまで独白が始まらないこと、送り切るまで帯が終わらないこと、経過時間でも走行距離でも進まないこと
- 余韻の間: 独白を送り切ってから暗転までに間が入ること。0 秒でも落ちないこと
- 暗転の出入り: 黒へは一瞬で落ち、明けるときだけフェードが掛かること
- `DriveWorld` のタイルの回し方: 環の添字と送る幅の計算を純粋な関数に切り出して確かめる
- `DriveDirector` の帯の順送り: 最後の帯の次が無いこと、帯 5 に入るまで `drive.window` が出ないこと
- `ArrivalClock`（場面 9 へのつなぎ）: 止まる音 → 間 → ドア → 村の順に進むこと、ドアの音から村まで決めた秒数であること、音はそれぞれ一度だけ鳴ること、走行音の下げ方、秒数が 0 や負でも詰まらないこと

## 9. 後続に委ねる事項

- 独白の本文と、帯ごとの行数。オーナーが決める
- 沿道の物の具体的な形と数。まず動く形を作り、実画面を見てから詰める
- 走行音・風切り音・仮眠前後の音の落とし方。素材の出典は `Assets/Audio/LICENSES.md` に足す
- 場面 9（村）との繋ぎ方は決まった（6 節の「場面 9 へのつなぎ」）。車を降りる動作は絵に出さず、場面 8 の末尾の黒のあいだに音だけで置く
  （車を止めてハンドブレーキを引く音 → ドアを閉める音）。場面 9 は車の脇に降り立った所（`BuildVillage.ArriveAt`、向き `ArriveYaw`）から、
  明けた絵で始まる。残っているのは、黒のあいだの秒数と音の大きさで、オーナーが耳で決める
