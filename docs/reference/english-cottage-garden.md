# イギリス田舎の庭と村並み 下調べメモ

『HALF AWARE』の一場面（イギリスの田舎の一軒家の庭と、そこへ至る村の路地）を作るための下調べ。対象は **豪邸やカントリーハウスの庭園ではなく、ふつうの家庭のコテージガーデン**。季節は真夏（8月中旬）、朝の場面と夕方の場面がある。

出典は各項目末尾に番号で示し、末尾の「出典一覧」で URL を確認できる。裏取りできなかった点は都度「未確認」と明記する。

## 1. コテージガーデンの植物

RHS（Royal Horticultural Society）を優先の出典としつつ、RHS のページが 404 で取れなかった種はガーデニング専門メディアで補った（表中に注記）。

### 開花時期についての前置き（重要）

デルフィニウム・ルピナス・ジギタリスは「コテージガーデンの定番」として真っ先に挙がるが、いずれも本来の花期は初夏〜盛夏（5〜7月）で、真夏 8 月中旬の時点では**咲き終えている、または切り戻し後の小さな二番花**であることが多い[^delph][^lupin-blog][^fox]。8 月の庭を作るなら、タチアオイ・バラ（返り咲き性）・ダリア・ルドベキア・エキナセア・スイートピー・ラベンダー・キャットミント・ゼラニウム（ペラルゴニウム）を主役に据え、デルフィニウム等は「穂の残骸」や「刈り込み後の株」として背景に混ぜる程度が実態に近い。

## 2. 田舎の家庭の庭の構成

### 前庭と裏庭の違い・広さの目安

- **前庭 (front garden)**: 道路に面し、通行のための半公共的な空間。物干しや家庭菜園、日光浴などは基本的に前庭では行わない、という社会的な慣習がある[^backgarden]。
- **裏庭 (back garden)**: より私的でカジュアルな空間。洗濯物干し、家庭菜園、日光浴などはここで行われる[^backgarden]。イギリスの典型的な戸建て・セミデタッチトハウスでは、前庭が道路と接して家へのアクセスを提供し、裏庭へは家の中を通るか、脇の通路を回ってアクセスする[^backgarden]。
- **境界の高さ規制（目安として）**: 前庭に面する境界フェンスは道路からの視認性確保のため高さ1m以下、裏庭・隣地境界は2mまでという規制がイギリスでは一般的[^fenceheight]。ここから「前庭は開放的で見せる庭、裏庭は囲われた私的な庭」という性格の違いが読み取れる。
- **広さの目安**: イングランドの庭の平均面積はおよそ255㎡（テニスコート1面程度）という調査があるが、地域差が大きく、イースト・オブ・イングランドや南西部・南東部（＝ロンドン近郊の田舎）は平均330〜335㎡、ロンドンは100㎡、北東部は187㎡と幅がある[^gardensize][^gardensize2]。新規開発向けの指針では裏庭の最低奥行きは9〜10m、前庭は4.5〜6m程度とされる例がある[^gardensize3]（自治体ごとの計画指針であり、実測の全国平均ではない点に注意）。
  - 本作が求める「豪邸ではないが、あずまや等も置けるちょっと広めの庭」であれば、**裏庭は奥行10〜15m×幅10〜15m（約100〜225㎡）程度**が目安として妥当と考えられる。カントリーハウスの庭園はヘクタール単位であり、桁が二桁以上違う。

### 裏庭の部品と並び方

家に近い側から奥に向かって、おおむね次の順で構成されることが多い[^cottage-elements][^gardenplanner]。

1. **家の裏口に近いテラス／パティオ**: 白いパラソル付きの卓と椅子など、座って庭を眺める場所。
2. **芝生**: 中心の広場。
3. **花のボーダー（花壇）**: 芝生や小路の縁に沿って帯状に植えられる。奥から手前へ背の高い植物→中くらい→縁取りの順に配置するのが基本[^bbc-border][^bbc-fiveplant]。
4. **小路**: 煉瓦・砂利・敷石など。ボーダーの花が小路にこぼれるように茂るのがコテージガーデンらしさ[^bbc-cottageplan]。
5. **構造物**: アーチ、パーゴラ、あずまや（後述）。バラやクレマチスを絡ませることが多い。
6. **温室**: ビクトリア様式の温室は尖った屋根と装飾的な鉄枠が特徴[^moonlight]。
7. **物置（ポッティングシェッド）**: 作業台・棚・換気口を備えた小屋[^moonlight]。
8. **野菜の畝**: 高床の菜園（ロー・ベッド）にすることが多い[^herb1]。
9. **果樹**: リンゴの木など（前掲）。
10. **堆肥箱・雨水の樽**: 家庭菜園の裏方[^lowes-english]。
11. **鳥の水盤・餌台**: 野鳥を呼ぶための小さな水場や餌台[^lowes-english]。
12. **物干し**: 家庭の裏庭にほぼ必ずある実用設備（この点は今回強い一次資料までは確認できなかったが、イギリスの裏庭における一般的な設備として広く知られている＝**未確認だが通説**）。

### 構造物の違い（アーチ／パーゴラ／あずまや）

- **アーチ (arbour)**: 最も単純な構造物。四角または半円のフレーム一つだけで、通路や庭の入り口を示す門型。ラティスや格子で作られ、バラなどを絡ませてトンネル状にすることも多い[^arbour1]。
- **パーゴラ (pergola)**: 柱と梁を組んだ開放的な構造物で、屋根はスノコ状（日陰と通風を両立）。通路を覆ったり、座る場所の上に設けたりする[^arbour1][^arbour2]。
- **あずまや (gazebo)**: 四方が開いた、完全な屋根（雨風をしのげる）を持つ独立した建物。床を備えることが多い[^arbour1]。
- **サマーハウス (summerhouse)**: 元来は「日陰の家」を意味し、散歩道の終点などに置かれた開放的な建物だったが、現在は電気・暖房を備えた本格的な小屋を指すことが多い[^arbour1]。
- 本作の「東屋」は、庭の一角に置く**あずまや寄りの東屋**（雨よけの屋根＋ベンチ）にするか、あるいは白パラソルの卓自体を東屋の代わりとして扱うかは設計判断。パーゴラ＋バラ／クレマチスの組み合わせも定番[^rhs-cottage]。

### 境界・門

- **境界**: 生け垣（トピアリーに刈り込まれることもある）、木の塀、ピケットフェンス（白い縦板の柵）、石垣がイングリッシュガーデンの定番の境界とされる[^gardendesign-boundary]。伝統的なコテージガーデンは家畜よけに低い野石の塀やピケットフェンスで囲われていたという説明もある[^mogers]。
- **門**: 白く塗られた木製のピケットゲートが最も定番。装飾的なラッチや鉄の蝶番を持つ、風化した木の質感を残すラスティックなゲートも人気[^gate1][^gate2]。開き戸に格子状の飾り板（レース状の透かし）を組み込んだデザインも典型的[^gate3]。

### 植え方の決まり事

- 密植（すきまなく植え、地面を見せない）。
- 小路へ植物がこぼれるように配置する[^bbc-cottageplan]。
- 背の高い植物を奥（後方）に、低いものを手前に配置する三段構成が基本[^bbc-border]。
- 同じ植物を3株・5株のまとまりで植えると効果的（奇数のまとまり）。ただしフウロソウのように一株ずつ点在させてボーダー全体をつなぐ使い方をする植物もある[^bbc-fiveplant]。
- 色は「ドリフト（帯状のにじみ）」を意識して混ぜ合わせ、雑多にならないよう事前にテーマ色を決めることが推奨される[^bbc-border]。

## 3. イギリスの村の家並みと路地

### 家の形と素材

- **コッツウォルズの石の家**: 地元産の石灰岩（オーライト）を使い、鉄分の含有量によって北部は茶色がかった濃い色、南部はクリーム色に近いなど地域差がある、いわゆる「ハチミツ色」の外観[^cotswold-stone]。採れたては白っぽく、数年風化させることで特徴的なハチミツ色になる[^cotswold-stone]。
- **屋根**: 本物のスレートではなく、現地の石灰岩を薄く割った「ストーンスレート」を使い、軒に近いほど大きく重い石版、棟に近いほど小さい石版を葺く、段ごとに小さくなる工法[^cotswold-stone]。切妻屋根は急勾配。
- **窓・戸**: 石の桟（マリオン）で仕切られた背の高い窓、上部に水切りの「フードモールド」。玄関はしっかりした石枠に木製の扉[^cotswold-stone]。
- **赤煉瓦の家**: 中部・南東部・イースト・アングリアで多く見られる。焼きたての赤色は経年でやわらかい色合いに落ち着く[^brick-cottage]。
- **茅葺き屋根**: 急勾配の屋根に用いられる伝統素材の一つ。石造・煉瓦造どちらの壁とも組み合わされる[^thatch]。
- **スレート屋根**: 一般に地方によってはウェールズ産スレートも広く使われるとされるが、今回の調査では一次資料までは確認できなかった（**未確認**）。
- **壁の仕上げ**: 石造でも「白く漆喰塗り（ホワイトウォッシュ）」にされた家がある。テューダー様式の白漆喰と黒い木枠（ブラック・アンド・ホワイト）の家も一部地域の特徴[^brick-cottage]。

### 路地の幅・構成

- 田舎の小道（レーン）は広い芝の路肩（グラス・ヴァージ）を伴うことが多く、これも道路の一部として扱われる[^laneverge]。ある保存地区の記述では、広い芝の路肩が歩道代わりとなり、生け垣・古木・低い花崗岩の縁石で縁取られている例が紹介されている[^laneverge]。
- 前庭の境界には低い野石の塀や刈り込まれた生け垣・トピアリーが使われる[^gardendesign-boundary]。
- 歩道が独立して整備されていない道も多く、車道と芝の路肩だけ、という構成が典型（**やや一般化した記述、個別の村により差がある**）。

### 村の小物

- **赤い電話ボックス（K6型）**: 1935年、ジョージ5世即位25周年を記念してサー・ジャイルズ・ギルバート・スコットがデザイン。鋳鉄製、コンクリート土台、王冠の意匠が入ったチーク材の扉、ドーム状の屋根が特徴。1960年までに約6万基が村の広場や街角に置かれた[^k6-1][^k6-2]。現在は電話用途を離れ、公共図書館やAED設置など地域用途に転用された例も多い[^k6-1]。
- **郵便ポスト**: 赤い円筒形のピラーボックスがイギリス郵便の象徴だが、本メモでは一次資料までは踏み込めていない（**通説として広く知られているが未確認**）。
- **フィンガーポスト（道標）**: 伝統的には木製または鋳鉄製の柱に、行き先を示す腕木（フィンガー）が複数付く。腕木は黒・白・グレーに塗られ、黒文字で行き先を書く。歩道・馬道の起点表示にも使われる[^fingerpost]。
- **フットパスの標識**: 黄色い矢印は「徒歩のみ通行可」を示す全国共通のウェイマーカー[^footpath]。
- **踏越し段（スタイル）・農場の門**: 牧草地の境界にある、人だけが越えられる階段状の仕切りや、家畜を通すための開閉式の柵門が田園地帯の路上でよく見られる（写真資料からの一般的な確認、詳細な形式差までは**未確認**）。
- **ベンチ・ハンギングバスケット・窓辺の花箱**: 街灯や建物の軒先から下げるハンギングバスケット、窓辺のプランターは村の景観要素として定番（ゼラニウムの項を参照）。
- **石垣**: コッツウォルズだけで約6,000kmの野石積みの塀が現存し、多くは18〜19世紀の囲い込み（エンクロージャー）時代に作られた。施工は門の位置から積み始めるのが伝統的な手順[^drystone]。

### 麦畑・丘陵からの見え方

- 起伏のある丘陵地に広がる黄金色の麦畑が、真夏のイギリス田園風景の典型的なモチーフとして頻繁に扱われる。ただしこの点は権威ある一次資料（学術・公的機関）ではなく、写真素材サイトや観光メディアでの一般的な描写に基づく確認にとどまる（**通説レベルの確認**）。
- 村の縁は、家と庭が徐々にまばらになりながら生け垣が畑の境界を形づくり始める場所として描写されることがある。世代を重ねて建てられた家並みが、周囲の景観と一体化していく様子が村の魅力とされる[^village-tradition]。

### ゲームの舞台としての典型的な並び（下調べからの構成案）

車を降りてから庭に着くまで（徒歩1分ほど）を、以下のような並びにすると典型的なイギリスの村らしさが出ると考えられる（**これは一次資料の要約ではなく、上記の調査結果を踏まえた設計上の提案**）。

1. 麦畑の間の未舗装路、または村はずれの路肩に車を停める。
2. 村に入ると石造または煉瓦の家が数軒、思い思いの間隔で並ぶ（[^village-tradition] にある「家々がまばらになる」記述に対応）。
3. 家々の間の隙間や生け垣の切れ目から、目的の庭の白いパラソルがちらりと見える。
4. 低い石垣・生け垣・ピケットフェンスに沿って歩き、格子の木戸（庭門）へ到達する。
5. 門をくぐると煉瓦の小路が奥へ弧を描き、テラスの白パラソルの卓へ続く。

## 4. ローポリで作るときの見せ方の手がかり

以下は今回集めた植物・建築の事実を踏まえた**構図上の提案**（一次資料の要約ではなく設計判断）。遠目で「イングリッシュガーデン」「イギリスの村」と一目で分かる、形と色の組み合わせを3つずつ挙げる。

### イングリッシュガーデンと分かる組み合わせ

1. **白いパラソル＋鉄の卓椅子＋煉瓦の弧を描く小路**: パラソルの白い円錐と、その下の黒い鉄脚のコントラストは遠目からでも視認性が高く、原作の記憶にも登場するモチーフでもある。
2. **タチアオイの垂直な穂＋ラベンダーの灰緑のこんもりした塊**: 「まっすぐ立つ植物」と「低くこんもりした植物」という2つの対照的なシルエットを花壇の奥と手前に置くだけで、ボーダー花壇特有の段差感が出る。
3. **格子の木戸＋その向こうに見える色とりどりの花壇**: 門の直線的な格子パターンと、奥のランダムな花の色の密集が対比になり、「これから庭に入る」という期待感を作れる。

### イギリスの村と分かる組み合わせ

1. **ハチミツ色（または赤煉瓦）の壁＋急勾配の石版（または茅葺き）屋根＋小さな窓**: 壁の暖色と屋根の急な三角形のシルエットの組み合わせは、コッツウォルズ系の村を一目で示せる。
2. **赤い電話ボックス、または赤い郵便ポストの小さな箱型シルエット**: 周囲がすべて自然な色調（石・煉瓦・緑）の中で、原色に近い赤の小さな箱がひとつあるだけで「イギリスの村」の記号として強く機能する。
3. **低い野石の塀・生け垣に縁取られた未舗装路＋その先に広がる黄金色の麦畑の丘**: 手前の低く抑えた緑〜グレーの帯と、奥の開けた黄金色の丘という色と高さのコントラストが、村はずれであることを一目で伝える。
