場面ごとの台詞の原稿を置く。**ここを正とし、ゲームの文面（`unity/Assets/Data/*Script.asset` や演出の Inspector の文）はここから写す。** オーナーが直接書き換えて添削し、写すのは CLaiRE 側の作業。

- [02-alley.md](02-alley.md) — 場面 2　路地裏

## 書き方の決まり（オーナー、2026-09-28）

- `- 「…」` の 1 行が、文字の窓の 1 ページ（送るまで出ている分）
- 会話は `- 話者「…」` と書く。字幕に話者の名が出る
- `<br/>` は改行。ページの中で行を改める。長い行は窓の幅で折り返す
- `<dot>…</dot>` は傍点（圏点）。囲んだ字の一つずつの上に点を打つ
- **それ以外の `<…>` はルビ。** 直前の字の並び（漢字なら漢字の続き、カタカナならカタカナの続き、英字なら英字の続き）が親字になる。例: `身体<からだ>`、`メモリ<記憶>`、`Stock<在庫>`
  - 親字の始まりを決めたい時（空白を挟む英語など）は `｜` を頭に置く。例: `｜No firewall<防壁なし>`
- **看板は英語で書き、日本語訳をルビで振る。** 読んだ時に画面の真ん中の枠に出し、「と書かれている」は付けない（オーナー、2026-09-29）
- **リスト（画面やメモに書かれた字）は日本語で書く。** 一度「英語にして日本語訳のルビ」と決めたが、全部にルビが付くと読みづらいので取りやめた（オーナー、2026-09-29）
- リストの列は、半角の空白 2 つ以上か全角の空白で区切る。半角の空白 1 つは同じ列の中
- `『…』` は声に出した言葉。そのまま『』付きで出す
- `"…"` で括った文は、オーナーから CLaiRE への指示（写した後に消す）
